# CHETAC Project Specification

## Vision

CHETAC is a data-driven digital asset technology project focused on
systematic market analysis, risk management, and transparent performance testing.

## Core Objectives

1. Collect and analyze market data.
2. Generate testable trading signals.
3. Apply defined risk-management rules.
4. Backtest strategies using historical data.
5. Evaluate performance using measurable metrics.
6. Maintain clear records of experiments and results.

## Development Principles

- Evidence before claims.
- Risk management before profit targets.
- Test before deployment.
- No real-money trading during initial development.
- Every major change should be version controlled.

## Initial Development Phases

### Phase 1 — Foundation
Project structure, documentation, configuration, and testing.

### Phase 2 — Market Data
Data ingestion, validation, and storage.

### Phase 3 — Strategy Engine
Signal generation and strategy rules.

### Phase 4 — Backtesting
Historical testing and performance analysis.

### Phase 5 — Risk Engine
Position sizing, stop-loss logic, exposure limits, and risk controls.

### Phase 6 — Paper Trading
Simulated execution without real capital.

### Phase 7 — Evaluation
Performance, drawdown, consistency, and robustness analysis.

## Investor Evidence

CHETAC should prioritize verifiable evidence including:

- Reproducible experiments
- Backtest results
- Risk metrics
- Testing history
- Version-controlled development
- Clear limitations and assumptions
